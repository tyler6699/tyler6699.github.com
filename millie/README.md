# Little Isle

A dependency-free, top-down JavaScript island game. Open `index.html` in a modern browser to play.

- Move with **WASD** or **arrow keys**.
- **Click** nearby trees (3 hits) or rocks (4 hits) to collect wood and stone.
- Press **Escape** to pause or resume.
- Touch devices have directional buttons; tap objects to interact.

The island has shoreline and object collisions, a following camera, an animated character, foliage, resource particles, and a live minimap. Resources reset when the page reloads.
